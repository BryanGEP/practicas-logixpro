# Prácticas de LogixPro (PLC)

Colección de prácticas de programación de **PLC** mediante **diagramas de escalera (ladder logic)**, desarrolladas en el simulador **LogixPro**.

Materia de Sistemas Programables — Instituto Tecnológico de Jiquilpan (TecNM), Ingeniería en Sistemas Computacionales.

## Contenido

Archivos de LogixPro (`.rsl`) con las prácticas del curso:

- **practica1.rsl** a **Practica12.rsl** — Prácticas numeradas de lógica de escalera.
- Incluye algunas variantes de tarea (`_Tarea_LP`).

Cada archivo `.rsl` se abre con el simulador LogixPro.

## Tecnologías

- LogixPro (simulador de PLC)
- Lógica de escalera (Ladder Logic)
